# 简单权限管理平台界面设计

状态：本轮实现基线，业务规则按《需求与范围》。界面使用 frontend-design 技能，定位为市政公司管理人员的日常授权工作台。

## 设计方案及审视

采用单个 Vue 3 工程。左侧为固定功能导航，右侧从标题与操作区进入密集但可读的业务表格；授权时使用列表加复选框的侧面板，先选对象再提交一次完整配置。以“谁获得什么权限”为主要操作，不以统计大屏开场。

配色：导航海军蓝 `#16324F`、纸白 `#FFFFFF`、工作区灰 `#F3F6FA`、正文墨蓝 `#203448`、操作青 `#087F8C`、错误红 `#B42332`。字体优先使用本机等线/微软雅黑，英文数字跟随系统无衬线；标题 24px、表格和控件 14px、说明 12px，明确左对齐，数字右对齐。

```text
┌──────────────┬───────────────────────────────────────────┐
│ 市政统一权限 │ 当前页标题                  当前账号/退出 │
│              ├───────────────────────────────────────────┤
│ 账号管理     │ 筛选与搜索                  新建/保存操作 │
│ 角色管理     ├───────────────────────────────────────────┤
│ 资源目录     │ 业务表格 或 目录树       │ 授权/编辑面板 │
│ 操作权限     │ 状态、版本、明确操作     │ 已选与可选项 │
│ 角色分配     │                           │ 保存/取消    │
│ 权限分配     ├───────────────────────────────────────────┤
│ 员工入口     │ 操作结果、错误及冲突反馈                  │
└──────────────┴───────────────────────────────────────────┘
```

方案审视后取消了装饰性的统计卡片、渐变和自动入场动画，将空间留给真实授权对象、状态与提交结果。青色只用于当前选择和主要动作；危险状态以文字加颜色共同表达。圆角主要用于控件与面板，表格本身保持清晰直线结构。

## 页面与状态

1. 账号：分页/搜索、创建、编辑显示名与员工关联、启停/锁定、凭据重置；角色分配及有效权限查看独立展示。
2. 角色：代码、名称、说明、状态；编辑时携带版本；分配权限在对应页面进行。
3. 资源目录：应用、模块、功能点的层次列表；创建及编辑不改变稳定代码，不允许错误层级关系。
4. 操作权限：资源和操作组成稳定编码，可启停；不以中文角色名决定访问。
5. 账号角色/角色权限：选定对象后读取当前配置和 grantsVersion，支持名称/编码查找及仅显示已选。隐藏项保留选择，提交前展示新增/回收清单，无变更时禁用保存；409 时由用户重新加载。旧对象或旧路由返回的异步响应不能作为新对象授权提交。
6. 管理入口选择：具备 platform:access 的账号登录后主动选择管理平台或员工入口；可在会话内切换。
7. 员工入口：当前账号、可用员工资料、组织、角色、有效权限及合成业务操作；无员工资料时显示明确空态。
8. 首页：展示管理与演示用途，以“账号密码登录”打开居中对话框；支持关闭、Esc、键盘焦点约束与关闭后焦点返回。登录后管理员选择入口、员工直接进入演示；会话到期重新打开登录窗口。
9. 会话状态：选择入口、管理和员工页面均显示剩余时间，窄屏保留可见。固定 30 分钟会话，任何刷新/切换不续期；普通无权为 403。

首页延续海军蓝、青色和浅灰配色：顶栏品牌及登录按钮，主体左侧说明和登录动作，右侧解释两个工作入口，窄屏改为纵排。审视后只保留一个主登录窗口，不增加可误解为独立认证系统的管理员/员工密码表单。测试密码最少 4 位仅为用户指定的本机演示策略。

所有页包含加载、空数据、服务不可用、校验失败与保存成功状态。按钮使用明确动词，写操作成功后重新获取服务端状态；会话过期清理客户端状态并要求登录。表单包含标签、键盘焦点和错误描述；窄屏折叠导航、表格横向滚动。提交期间禁止重复点击。

开发时前端默认访问 `/api`，Vite 只代理本机后端；生产构建由同一后端提供，使用同源 Cookie。界面只展示合成账号和脱敏员工标签，不渲染原始姓名或电话。具体截图与浏览器验收结果写入测试记录。
