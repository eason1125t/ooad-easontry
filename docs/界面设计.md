# 界面设计说明

版本：0.2.0；管理员平台与独立公文系统均已实现。

## 权限管理平台

8080 首页仅提供管理员登录；输入账号和密码后直接进入概览。移除原员工登录与演示入口选择，旧演示接口已移除。页面显示当前身份及到期时刻，后台按固定 1800 秒强制失效，页面活动不续期。

管理导航包含账号、角色、资源、操作权限、员工角色分配、管理账号角色、角色权限等。账号可选关联脱敏员工；员工列表支持分页、组织与合成标签搜索、精确编号查找。员工角色配置区只列业务角色，管理账号配置区只列管理角色；角色权限配置按应用用途过滤，服务端重复验证边界。

员工角色分配支持启停员工、选择目标、比较当前和待保存角色、按版本保存；“公文合成员工”快捷查询固定合成资料。列表限制高度并滚动，使授权区在窄视口仍可操作。真实姓名和电话不显示。版本冲突提示重新读取，不能静默覆盖。

## 独立公文系统

9090 提供绿色导航、身份选择、权限状态、公文目录和编辑区。身份入口明确标注本机合成验证，无普通员工密码。编辑员工可保存，阅读员工只读。权限提示用于交互反馈，每次后端读取或保存仍实时调用权限平台。

正文采用纯文本展示与编辑，数据写入使用 textContent/value，不执行服务端返回的 HTML。保存成功显示新版本；API 同时返回鉴权 requestId；403、409、503 分别提示权限不足、版本冲突和鉴权不可用，并保留输入供核对。页面在窄屏切换为上下结构。
