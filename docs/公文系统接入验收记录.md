## 适用限制与后续方向

两个服务均只监听本机 HTTP。公文入口是两个预设合成员工的身份模拟，无真实密码登录或 SSO；业务会话保存在公文进程内。公文 H2 文件库为本期独立存储方案，不属于权限 MySQL ER。未实现公文审批、附件、数据范围、RBAC1/2、真实身份接入或吞吐/延迟验收。

建议先按照[运行指南](公文系统运行指南.md)手动复验授权与回收，再在独立 Windows 环境按[安装指南](新环境安装运行指南.md)复现。之后确定真实员工身份源、应用密钥运维和 HTTPS，再扩展业务功能；不应把“接口返回允许”表述为“公文已修改成功”。
