# 朋友电脑首次运行（Windows）

适用于从 GitHub 全新克隆、在另一台 Windows 电脑上独立体验 RBAC0。数据库和账号在朋友自己的电脑生成；网页地址仍是他本机的 http://127.0.0.1:8080，不需要连接项目作者的电脑。

## 取得代码

仓库是私有的。有两种方式：

1. 持有者在 GitHub 仓库 Settings → Collaborators → Add people 邀请朋友的 GitHub 用户名；朋友接受后，用自己的账号克隆。个人私有仓库的协作者同时拥有写权限，不能只授予只读；若只是试运行，也可由持有者下载源码 ZIP 后私下交给朋友。
2. 使用此前生成的源码评审 ZIP，解压后直接从下一节开始。ZIP 是当时的快照；想使用最新代码应从仓库下载或克隆。

官方说明：[邀请协作者](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository)、[个人仓库权限](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository)。

在已完成 GitHub 登录的终端中：

```powershell
git clone https://github.com/eason1125t/ooad-easontry.git
Set-Location ooad-easontry
```

Repository not found 常见于没有接受私有仓库邀请，或 Git 使用了另一个账号。也可以登录 GitHub 网页，打开仓库 Code → Download ZIP，再解压。

## 安装运行环境

以下版本与项目当前实现相匹配：

| 环境 | 要求及用途 |
| --- | --- |
| JDK 21 | 需要 java 和 javac，运行及编译后端 |
| Node.js 24 | 自带 npm，安装和构建前端 |
| MySQL Server 8.4 | 本机服务 localhost:3306；需自己的 root 管理密码 |
| Python 3.12（带 tkinter、pip） | 运行本机初始化窗口 |
| Git | 克隆及后续更新；使用源码 ZIP 时可不装 |

Navicat、Apifox、独立 Maven 均不是网页试运行的前置条件。仓库提供 Maven Wrapper，首次构建会联网下载 Maven 与 Java 依赖；npm 和 pip 也需要能访问各自的软件源。

安装后重开 PowerShell，确认 PATH 与 JAVA_HOME 配置可用：

```powershell
java -version
javac -version
node -v
npm.cmd -v
py -3.12 --version
mysql --version
```

mysql 命令若不存在，可使用 MySQL 自带命令行客户端，或把安装目录的 bin 加入 PATH 后重开终端。以下命令默认当前目录一直是项目根目录，除非步骤明确切换。

## 安装项目依赖

```powershell
py -3.12 -m pip install --target .tools/setup-deps "PyMySQL[rsa]==1.1.2" "bcrypt==4.3.0" "openpyxl==3.1.5"
npm.cmd ci --prefix frontend
```

Python 包放在本机 .tools/setup-deps，初始化工具会从该位置加载。rsa 额外依赖支持 MySQL 的密码认证。前端使用 package-lock.json 安装锁定的版本。

## 建立独立空开发库

先确保 MySQL 服务在运行。从项目根目录打开 MySQL 客户端，密码在本机提示中输入：

```powershell
mysql -u root -p
```

在 MySQL 提示符内执行：

```sql
SOURCE database/environment/create-development-database.sql;
EXIT;
```

该 SQL 创建 municipal_access_ooad_dev，预期返回 table_count=0；它故意不复用已有同名库。如果已经存在同名库、municipal_access_ooad_test 或 municipal_ooad_app / municipal_ooad_migrator 用户，先停止并核实用途，不删除已有库或强行重复初始化。

## 初始化朋友本机的凭据

回到项目根目录的 PowerShell：

```powershell
py -3.12 scripts/setup_local.py
```

在弹出的本机窗口填写：

- MySQL root 密码：朋友这台电脑安装 MySQL 时设置的管理密码。
- 网页管理员用户名：保留 project_admin。
- 网页管理员密码、demo_user 密码：本机课程试用可以都填 1234，也可自行设置其他符合规则的密码。

点击“配置本机环境”，应提示完成。它创建独立测试库以及仅访问项目库的应用/迁移账号，将随机数据库密码和网页密码哈希写入朋友本机的 .local。MySQL 密码和网页密码是不同用途，不需要相同。

如果提示本机配置已存在，说明已经做过初始化。继续下一步即可；不要通过删除配置、重建用户来重置现有环境。

## 首次构建和启动

第一次用以下命令逐步构建，便于看到错误。当前从项目根目录开始：

```powershell
npm.cmd run build --prefix frontend
Set-Location backend
.\mvnw.cmd -B -ntp -DskipTests package
java -jar target\access-platform-0.1.0.jar
```

每一步成功后再执行下一步；失败时保留首个错误信息，不继续启动旧构建。最后一条命令运行期间保留终端打开；看到 Spring 启动成功后，浏览器打开 http://127.0.0.1:8080。健康检查 http://127.0.0.1:8080/api/health 应返回 status=UP。在该终端按 Ctrl+C 可停止平台。

后续可以按《运行与使用》使用 Start-Platform.ps1 / Stop-Platform.ps1 管理后台进程；首次克隆没有 JAR，不能直接使用 -SkipBuild。8080 已被其他程序占用时先确认占用者，不终止未知进程。

## 登录和试用

首次启动会执行三次迁移，创建合成种子并初始化两个账号。按上述设置密码时，账号为 project_admin / 1234 与 demo_user / 1234；如果自己设置了不同密码，使用自己填写的值。

| 登录账号 | 预期行为 |
| --- | --- |
| project_admin | 显示管理平台/员工演示双入口，可维护账号、角色和授权 |
| demo_user | 自动进入员工演示，点击读取受保护文档，返回 DOC-001、DOC-002 两条合成文档 |

新电脑默认是 2 个账号、2 个角色、2 个合成组织、1 个合成员工、12 个资源节点、13 项权限，与作者导入完整资料后的数量不同。flow_user 是后续演练脚本创建的账号，不会在全新启动时自动存在。

三份原始 Excel 没有放进 GitHub，它们不是基本网页试用的必要输入；此次不执行 import_sources.py。需要体验万条来源员工导入时，再另行准备经授权的原始资料和首次导入流程。完整数据库快照另有来源员工、密码哈希及会话，不适合作为朋友首次试用的默认安装数据。

可按“管理员建立合成账号 → 给角色分配文档权限 → 给账号分配角色 → 普通账号读取 → 回收后再读取”的顺序体验。两个身份使用独立浏览器配置或普通/无痕窗口，同一主机的普通标签页共享 Cookie。固定会话 30 分钟，不会因操作续期。

## Apifox（可选）

在朋友的 Apifox 新项目中导入 docs/api/openapi.json，选择所有引用模型及鉴权组件；环境前置地址为 http://localhost:8080，路径已含 /api。朋友自己登录其本机网页账号取得 Cookie 与 CSRF，写请求使用 X-CSRF-Token，不沿用作者的会话。

网页试运行无需安装 Apifox。SQL 结构由 Flyway 自动迁移，也不需要在 Navicat 再执行整套建表脚本。

## 核对范围与后续

上述流程已对照初始化源码、迁移种子、Maven Wrapper 和前端锁文件核对，Python 依赖版本取自本项目已使用的环境。尚未在朋友的具体电脑上执行完整新机安装，不将源码核对当作那台电脑已经运行成功。

运行遇到问题时，提供失败步骤、软件版本及首个错误文本，去掉密码和会话值。先用合成数据跑通两个账号，再按[首检演示脚本](首检演示脚本.md)体验授权回收；环境总览见[运行与使用](运行与使用.md)。
