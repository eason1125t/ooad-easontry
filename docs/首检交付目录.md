## 源码与脚本

| 路径 | 用途 |
| --- | --- |
| backend/src、backend/pom.xml、backend/.mvn、backend/mvnw* | Java / Spring / MyBatis 源码、真实 MySQL 测试、Flyway 迁移与 Maven Wrapper |
| frontend/src、frontend/test、frontend/package*.json、前端配置文件 | Vue / TypeScript 页面、筛选与授权差异测试、锁定依赖 |
| database/environment、database/history | 开发库准备 SQL 与保留的失败迁移原件；实际有效迁移位于后端资源目录 |
| scripts/Start-Platform.ps1、Stop-Platform.ps1 | 本机构建、后台启动和受控停止 |
| scripts/setup_local.py、audit_sources.py、import_sources.py | 本机初始化、三份原件只读审计与首次导入 |
| scripts/verify_platform.py、verify_apifox.py、run_walkthrough.py | HTTP 契约检查、Apifox 导出比较与完整合成授权复演 |
| scripts/build_design_docs.py、render_er.cjs | 设计资料及 ER 图的生成工具 |
| scripts/package_delivery.py | 新建评审目录与 ZIP，校验文件哈希、包内链接及压缩包内容 |

本机评审包放在项目根目录 deliverables/ 下的带时间目录及同名 ZIP，保留原有目录层级；MANIFEST.json 记录每个文件的大小及 SHA-256，方便核对。包内先读本文件和演示脚本。每次生成新目录，不覆盖以前的包，也不删除原文件。

复现：在项目根目录执行 `python scripts/package_delivery.py`。同名 `.verification.json` 位于 ZIP 旁边，记录实际检查结果、压缩包 SHA-256 和文件数。该工具只打包和核验，不启动测试、不替代已有测试记录。

包包含设计资料、源码、SQL、工具、聚合测试证据和演示截图；不包含 .local 本机配置、数据库凭据、会话数据、.tools、node_modules、target/dist 或三份原始 Excel。当前已构建 JAR 和运行中的数据库仍留在原工作区。需要在新电脑运行时，应按运行文档准备环境、独立数据库和本机凭据；源码评审包不是已经验证过的免配置安装包。完整来源导入需另行取得原始资料，并遵循首次初始化规则。
