## 优化内容

| 问题 | 改进 |
| --- | --- |
| 用户、账号术语容易混淆 | 保存《账号员工与角色说明》，界面统一为“账号角色分配”，保留 user_role 表名及原路由标识 |
| 员工关联需要手填编号 | 编辑账号时提供员工查找、分页、精确编号及组织/合成姓名查询；真实员工只显示编号，已占用的关联不可选 |
| 已有关联冲突提示笼统 | 并发关联仍由数据库约束拦截，返回 EMPLOYEE_ALREADY_LINKED 和可操作的反馈 |
| 504 个资源不便定位 | 名称/代码及启用状态筛选；保留匹配项祖先，区分匹配数和展示数，提供无结果提示 |
| 授权列表不便查找 | 名称/代码搜索、仅显示已选；筛选不删除隐藏的已选 ID；账号对象支持搜索和翻页 |
| 保存前不易看清影响 | 展示新增/回收清单；未修改时不能保存；切换对象或路由后旧响应不能成为当前授权配置 |

员工选择只修改账号表单，点击账号保存后才写入；该阶段浏览器验收取消了表单，没有把真实员工绑定到共享测试账号。原始 Excel、现有业务授权和数据库结构未改变。
