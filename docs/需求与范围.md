# 需求与首检范围

版本：0.3，2026-10-21。首检范围已据用户确认实现本机 RBAC0 初版，执行证据见《测试与验收》，尚不等于教师验收。来源为根目录启动说明、三份原始 Excel 和本聊天明确决定；不继承旧工程完成状态。

## 目标与系统边界

建设市政公司的统一权限管理系统，为三门课程提供可运行软件、结构化分析与设计、数据库、API、测试及使用资料。主线是维护账号、角色、资源、操作权限和授权关系，并由后端执行鉴权。

企业应用清单用于建立资源目录和挑选少量受保护演示操作；不开发整套 OA、财务、HR 或 18 个企业应用。组织树不等于角色继承；岗位不等于权限角色；一万名员工不等于万级并发。
