## 核心编码分批顺序

1. 固定兼容依赖、Maven Wrapper、前后端构建及配置方式；建立健康检查和最小 MySQL 连接。准备受忽略的本机配置，应用账号与数据库管理账号分开。
2. 实现账号、角色、资源及操作权限基础过程；配套输入校验、约束与正常/冲突测试。凭据字段此时已设计，正式登录仍后置。
3. 实现用户角色和角色权限分配/回收，以及事务失败回滚、配置并发冲突反馈。
4. 实现有效权限并集与去重，验证角色/权限/账号停用、多重授权路径和普通账号无权。按 D-16 保证提交后的新鉴权读取新权限；避免长事务快照沿用旧授权。
5. 准备管理页面接入。正式登录前只在测试中使用可信身份上下文，不开放匿名业务接口或用可伪造的 `X-User-Id` 临时冒认。
6. 最后编码正式登录、管理员入口选择与切换、员工入口、合成业务操作及 30 分钟绝对过期；完成后才进入完整 HTTP/页面身份联调、回归和演练。

| 界面原型 | 工作台、账号/角色、资源/权限、分配回收、登录和入口状态 | 实际打开页面；含无权、空态、加载、输入错误和冲突反馈 |
| API 资料 | 需求、方法/路径、请求响应、校验、鉴权、数据范围、错误、示例、状态 | Apifox 写入后回读；明确区分设计状态和实现状态 |

| 首次初始化工具 | 三份完整资料预检、来源映射、结果报告及受控初始化 | 错误维度不截断、合并组正确；真空白不自动授权；不生成公开默认密码 |
| 身份与合成演示 | 登录、双入口、少量真实受保护操作、30 分钟过期 | 401/403、普通账号越权、到期边界、多标签/刷新不续期 |
| 测试与运行说明 | 实际命令、环境、结果、未完成项、运行/演示步骤 | 区分未执行、失败、阻塞、通过；不把命令清单当执行记录 |

建议演示：给合成账号分配角色及某资源操作权限，成功访问；回收后发起新鉴权，请求被拒；再验证普通账号不能访问管理 API、停用行为和绝对过期。回收测试需同时覆盖仍存在其他角色授权路径时访问继续成功。

过期边界优先用可控时钟验证登录后 1,799 秒、恰好 1,800 秒和超过 1,800 秒的行为；若演示缩短时长，使用独立测试配置并明确标注。正式规则始终为 1,800 秒。
