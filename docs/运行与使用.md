# 系统运行与使用

当前版本 0.2.0 包含两个独立 Java/Spring 服务。权限管理平台为 <http://127.0.0.1:8080>，仅管理员登录；公文系统为 <http://127.0.0.1:9090>，用于合成员工身份与服务端鉴权验证。

首次安装、依赖、数据库及初始化步骤见[新环境安装运行指南](新环境安装运行指南.md)。日常启动、停止、授权撤权演示及故障处理见[公文系统运行指南](公文系统运行指南.md)。

本机管理账号 project_admin，测试密码 1234；新环境以初始化设置为准。普通员工无权限平台密码。旧 demo_user、flow_user 已停用，不能继续作为登录样例。合成员工编号以当前页面为准。

源码更新后须停止对应进程并重新构建，不使用旧 JAR 验证新代码。当前后台启动和停止脚本记录本项目绝对路径与 PID，拒绝处理其他目录或未知端口的进程。本机私有配置、原始员工资料、数据库文件不进入 Git 或公共交付包。

验收结果见[公文系统接入验收记录](公文系统接入验收记录.md)。历史单体演练保留原件，不能用作当前独立公文系统的验证结论。
