## 真实页面操作

1. project_admin 登录 127.0.0.1:8080，显示双入口及会话倒计时；进入权限管理平台。
2. 打开“角色权限分配”，选流程演练阅读角色 A，确认已有 1 项文档权限。搜索 demo.documents，取消勾选，页面预览新增 0、回收 1。
3. 实际点击“保存授权配置”，显示“授权配置已保存，后续鉴权立即使用新权限”，已选 0 项。此次确实提交，与上一轮未提交预览不同。
4. 退出管理员，以 flow_user / 1234 登录，自动进入员工入口，没有管理菜单；有效权限 0 项。点击“读取受保护文档”，页面显示“当前账号没有执行此操作的权限”。页面本身只展示友好反馈；403 状态另由接口复演确认。
5. 保持上述员工会话。在独立主机地址 localhost:8080 登录 project_admin，进入角色权限分配，选同一角色 A；重新勾选文档权限，预览新增 1、回收 0，实际保存成功。
6. 返回原 127.0.0.1 员工窗口，没有重新登录，直接再次点击读取：显示“后端已完成权限检查，文档读取成功”，有效权限 1 项，并显示 DOC-001、DOC-002 两条合成文档。倒计时继续从约 29:37 减少至 28:03，没有恢复到 30:00。
7. 退出并关闭临时 localhost 管理员窗口。原员工窗口保留结果供复查；最终业务授权恢复为演练前的最小阅读状态。

本次利用 localhost 与 127.0.0.1 的主机 Cookie 隔离保持两个身份；这两个地址指向同一个本机后端。现场更推荐独立浏览器配置或普通/无痕窗口，避免误切账号。
