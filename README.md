# 市政公司统一权限管理系统

基于 Java 21、Spring Boot、MyBatis、MySQL 的 RBAC0 权限服务，Vue 3 / TypeScript 管理前端，以及独立 Spring 公文业务系统。Python 仅承担初始化、导入、验证和交付工具，不承担在线业务。

## 当前版本 0.2.0

当前进度、保存范围与后续安排见[当前进度与后续计划](docs/当前进度与后续计划.md)。2026-10-22 已确认将真实员工登录或 SSO 留到后续阶段，本期保留明确标注的合成身份验证。

权限平台仅供管理员登录，保留固定 30 分钟会话、CSRF、管理功能与最后完整管理员保护。业务角色直接分配给员工，普通员工无需权限平台账号密码。独立公文后端在每次读取或保存前通过应用密钥调用批量鉴权接口，权限服务不执行公文业务。

| 项目 | 已实现范围 |
| --- | --- |
| 管理 | 账号、角色、资源、权限管理；账号管理角色、员工业务角色与角色权限分配、启停和版本保护 |
| 鉴权 | 单员工 1–50 个精确权限、逐项结果、应用范围隔离、同批一致性、无权限缓存、异常拒绝 |
| 公文 | 独立会话、合成员工身份选择、两条合成公文读取与编辑、版本冲突和成功审计 |
| 数据 | MySQL 17 张业务表及 Flyway 历史表；独立 H2 公文文件库；原始资料保留且不自动授权 |
| 契约 | RBAC 30 个操作；公文 8 个操作；OpenAPI 可分别导入 Apifox |
| 验证 | MySQL 集成 25 项、公文集成 6 项、前端 4 项；当前 HTTP 与完整联调见验收记录 |

## 安装与运行

首次安装按[新环境安装运行指南](docs/新环境安装运行指南.md)准备 JDK 21、Node/npm、MySQL 8.4 与 Python，创建本机独立凭据。Navicat、Apifox 为可选工具。

已初始化环境在项目根目录执行：

```powershell
.\scripts\Start-Platform.ps1
py -3.12 scripts/configure_integration.py
.\scripts\Start-Documents.ps1
```

管理平台 <http://127.0.0.1:8080>，公文系统 <http://127.0.0.1:9090>。本机管理员 project_admin / 1234；新环境以初始化设置为准。普通员工无平台密码，公文入口使用明确标注的合成身份模拟。该模拟不能替代真实业务登录。

更新源码前先停止两个已确认属于本项目的进程，再重新构建。源码不变且已有最新 JAR 时可使用 -SkipBuild。具体授权、撤权与恢复步骤见[公文系统运行指南](docs/公文系统运行指南.md)。

## 工程与文档

| 目录 | 职责 |
| --- | --- |
| backend/ | 权限服务、MyBatis、Flyway、MySQL 集成测试；JAR 包含管理前端 |
| frontend/ | 管理员 Vue 前端与前端回归 |
| document-system/ | 独立 Java/Spring 公文服务、静态页面、H2 与集成测试 |
| database/ | 环境 SQL 与历史；有效迁移位于 backend/src/main/resources/db/migration |
| scripts/ | 初始化、首次资料导入、启动停止、联调、文档与打包 |
| docs/ | 正式设计、运行指南与保留版本的验收证据 |

主要入口：[文档目录](docs/项目文档目录.md)、[账号员工角色说明](docs/账号员工与角色说明.md)、[公文设计](docs/公文业务系统设计.md)、[数据库 ER](docs/数据库ER.svg)、[API 设计](docs/API设计.md)、[接入验收](docs/公文系统接入验收记录.md)。

原始 Excel、.local/、.tools/、依赖与构建产物不纳入版本管理。应用密钥只在公文后端本机配置中，不能写入浏览器或公共环境。来源组织、岗位和候选模板不自动转化为授权。迁移前备份保留在本机，已应用 SQL 不改写。
